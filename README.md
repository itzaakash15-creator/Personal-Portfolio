# AAKASH K — Personal Portfolio Website
> **"NOTHING CHANGES IF NOTHING CHANGES."**

A premium, futuristic, highly interactive personal portfolio website positioning **AAKASH K** as a young student entrepreneur, Personal Branding Strategist, Digital Marketer, Content Creator, and future founder.

---

## ⚡ Visual Aesthetics
- **Dark Charcoal / Deep Midnight Theme:** Subtle layered surfaces with depth (`#08070d`, `#0d0b14`, `#13101c`).
- **Electric Violet & Purple Gradient System:** Highlights, glowing borders, and luminous accents (`#a855f7` → `#7928ca`).
- **High-End Interactive Micro-Animations:** 
  - Interactive HTML5 Canvas orb background responding to cursor velocity.
  - Custom Desktop Cursor with smooth lerp physics and card morph states (`VIEW ↗`).
  - Draggable Before / After video transformation slider.
  - Interactive case study modals with challenge, strategy, execution, and impact.
  - Dynamic skills wall with category filtering.
  - Viewport-triggered animated statistic counters.
  - Full Mobile Responsiveness: Dedicated app-style slide-out navigation drawer, fluid typography scaling, touch-enabled transformation slider, and adaptive single-column card grids.

---

## 🛠️ Architecture & Tech Stack
- **Core:** Semantic HTML5 & Modular ES6 JavaScript.
- **Styling:** Vanilla CSS3 with custom design tokens, glassmorphism, and hardware-accelerated animations.
- **Zero Build Dependencies:** Blazing fast 60–120 FPS performance, lightweight, and native browser compatibility.

## 🚀 Running Locally
Open `index.html` directly in any browser, or start a local HTTP server:
```bash
python3 -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).
