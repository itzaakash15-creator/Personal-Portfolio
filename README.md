# AAKASH K — Personal Digital Command Center
> **"NOTHING CHANGES IF NOTHING CHANGES."**

A futuristic, premium, highly interactive personal digital command center for **Aakash K** — combining the aesthetics and precision of a **premium creative agency**, **modern AI/product website**, **editorial portfolio**, **personal operating system**, and **high-end startup landing page**.

Designed around the core principle: **80% Premium Editorial Design + 20% Futuristic Technology**.

---

## ⚡ Core Visual & Interaction Identity
- **Dark Cinematic Interface:** Near-black background (`#060609`), subtle layered dark surfaces (`#0a0a10`, `#100f18`), and restrained purple/indigo atmospheric lighting (`#8b5cf6`, `#6366f1`).
- **Fine Technical Grid & Constellation Canvas:** Delicate interactive particle constellation with cursor-reactive illumination and zero generic 3D blobs.
- **Minimal Fixed Navigation + Command Palette (⌘K / Ctrl+K):** Real-time search, quick navigation, direct email copying, and social channel dispatch.
- **Fullscreen Navigation Overlay:** Large editorial typography showcasing sections `01` through `07`.
- **Verified Signals & Metrics:** Strictly verified performance numbers (`59K` Peak Life With Aakash reel, `3K+` Purple Collection followers, `2025` Best Reels Creator, `2025` Young Informative Content).
- **Large Editorial Project Blocks & 7-Part Agency Case Study:**
  - `01 THE CHALLENGE`
  - `02 MY ROLE`
  - `03 THE APPROACH`
  - `04 THE WORK`
  - `05 THE RESULT`
  - `06 THE PROOF`
  - `07 NEXT PROJECT`
- **Interactive Transformation Slider:** Before vs. After video framing & perceived value slider with keyboard support.
- **Creator → Builder Journey:** Interactive horizontal/vertical timeline spanning 2020 through Next Stage.
- **Digital Lab:** Categorized technical hardware & software showcase (Jayashakthi Web Platform, Smart India Hackathon MineGuardian, ESP32 Fire Hub, GrandCare, PowerSense).
- **Skills Constellation:** Interactive mapping linking disciplines directly to real-world deliverables without fake percentage bars.
- **Web Audio API Micro-Feedback:** Synthesized micro-chimes and clicks (optional toggle with on/off states).
- **Custom Desktop Magnetic Cursor:** Smooth lerp physics and magnetic attraction.

## 🚀 Running Locally
Open `index.html` directly in any modern browser, or launch a local web server:

```bash
# Using Python
python3 -m http.server 4173

# Or using Node.js
npx serve .
```

Then visit [http://localhost:4173](http://localhost:4173).

### Keyboard Shortcuts
- `⌘K` or `Ctrl+K`: Open Command Palette
- `W`: Jump to Selected Work
- `L`: Jump to Digital Lab
- `J`: Jump to Journey Timeline
- `C`: Jump to Contact
- `ESC`: Close Modals / Command Palette
